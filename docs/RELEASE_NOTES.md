## Clearlist 0.1.3

- Automatically checks for updates when the app opens.
- Adds Settings → Updates with a manual check, release notes, and download progress.
- Asks before installing and restarting; saves pending edits before installation.
- Adds an unassigned, customizable Check for updates hotkey.
- Provides native Windows 10/11 installers for x64 (Intel/AMD) and ARM64.
- Verifies update signatures before installation. Task data stays local.

Install this version once on each PC to enable future in-app updates. Close Clearlist and run the installer over the existing version. Lists, notes, images, and settings are preserved. Choose x64 for Intel/AMD; choose arm64 for Windows on ARM. No GitHub account is required to download or update.

Updater signatures verify downloads inside the app. A Windows Authenticode certificate is not configured, so Windows may show an unknown-publisher warning for the initial installer.
